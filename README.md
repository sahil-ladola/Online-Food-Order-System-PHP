# 🍕 Online Food Order System (PHP)

Welcome to the **Online Food Order System** repository!  
A web-based platform designed to enable customers to place takeaway orders, help restaurant managers oversee operations, and allow admins to efficiently manage all aspects of the restaurant system—built with PHP.

---

## 🚀 Features

- **Customer Ordering:** Browse menu items and place takeaway orders online.
- **Order Management:** Restaurant managers can view, process, and track incoming orders.
- **Admin Panel:** Full system control—manage menu, users, and restaurant settings.
- **User Authentication:** Secure registration and login for customers, managers, and admins.
- **Real-time Status Updates:** Track order progress from placement to completion.
- **Database Integration:** Reliable storage and retrieval of data with MySQL.

---

## 🛠️ Tech Stack

- **Language:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript

---

## 📂 Project Structure

- `/customer/` — Customer-side website for placing orders.
- `/restaurant/` — Restaurant manager-side website for handling orders and management.
- `/admin/` — Admin-side website for full system access and management.
- `/images/` — Favicon, logos, and other images.
- `/assets/` — CSS and JS files for styling and interactivity.

---

## 💡 Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/sahil-ladola/Restaurant-Food-Order-PHP.git
    ```
2. **Set up the database:**  
   Import the provided SQL scripts in `/sql/` to your MySQL server.
3. **Configure database connection:**  
   Update database credentials in the config file as needed.
4. **Host the project:**  
   Use XAMPP, WAMP, or any other PHP-compatible server.
5. **Access via browser:**  
   Navigate to the appropriate folder (`customer`, `restaurant`, or `admin`) to use the respective interfaces.
